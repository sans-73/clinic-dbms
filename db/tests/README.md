# Rule tests
- `rule_tests.sql` (generated by `tools/gen_rule_tests.py`): 127 tests. Run:
  `docker compose exec -T mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" clinic_db' < db/tests/rule_tests.sql`
  Output: one row per test (`PASS`/`FAIL`, rule number, name, detail), then a summary row. Re-runnable (fresh random data per run).
  A FAIL row names the rule: fix the owning file (see `docs/pooling/IMPACT_MAP.md`) and re-run.
- `forbidden_actions.sh` (generated by `tools/gen_security.py`): logs in as each restricted MySQL account and tries forbidden actions; every line must say PASS (refused).
- Add a test: append `test(rule, name, action, 'error'|'ok'|'assert', ...)` to `tools/gen_rule_tests.py`, regenerate, run.
